## Engine gaps

- The types of `createGlobalTheme` do not map a digit key of a DTCG override (`"0"`) to the token's `_0`: `createGlobalTheme(t, media("(prefers-color-scheme: dark)"), { ansi: { $type: "color", "0": { $value: "#000" } } })` over `createTokens({ ansi: { $type: "color", "0": { $value: "#fff" } } })` is TS2345 ("has no properties in common"). docs/API.md's Figma bullet says a DTCG file as a theme maps `500` to `_500`. Workaround: the ANSI colours are named (`black` .. `brightWhite`).
