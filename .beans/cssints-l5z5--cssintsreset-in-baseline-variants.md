User (2026-10-11): Baseline variants for the reset package, as cssints has export groups. `@cssints/reset/widely-available`, `/newly-available`, `/baseline-YYYY`, the `/with-downstream` ones (the Baseline groups of cssints, not the spec groups); `@cssints/reset` stays everything. A variant keeps only the declarations (and selectors, e.g. :where, ::backdrop) whose features are in the group, from the group data of cssints, not a hand list.

- [x] a plugin-side check in cssints/plugin (is this declaration/selector in group X), reusing groups-data
- [x] reset subpaths generated or a pattern export; README table of what each variant drops
- [x] tests (which declarations each variant has), types, docs, changeset (minor)

## Summary of Changes

- **Helper:** `inGroup(group, property, value)` in `cssints/plugin` (scope.ts front, `engine.inGroup`, group.ts): true when the group has the property and the value holds no word it bans, the scan that `cssints/<group>` runs on a call, from groups-data. A property cssints has no member for (`--x`, `-webkit-text-size-adjust`) is in every group; `limited-availability` is everything; an unknown group throws. Documented in docs/API.md ("Plugins"), the plugin skill; test in test/scope.mjs. The data has no selector features (only pseudo-classes without arguments), so selectors are kept as written; documented in API.md and the reset README (`baseline-2015` to `2020` keep `:where()` rules, only their declarations are filtered).
- **Reset:** the rules are data in `src/make.ts`; `make(group)` filters them with `inGroup` and drops a rule left empty. `src/index.ts` is `make()`. 29 generated modules `src/groups/<id>.ts` (scripts/variants.ts, `bun run variants`), one per Baseline group of cssints plus `limited-availability`; `not-discouraged` has none (it bans nothing the reset uses; the test checks). Pattern export `./*` (development source, types and dist), built as `dist/groups/<id>.mjs/.d.mts`; a name that is no variant has no declaration file, so it is a type error (test/types/reset.ts).
- **Drops** (README table, generated by `node test/reset.mjs --write`, checked by the test): widely-available and 2020-2023: `text-size-adjust`, `text-wrap: balance/pretty`; newly-available and 2024-2026: `text-size-adjust`, `text-wrap: pretty`; 2018-2019 also the logical sizes and `margin-block-start`; 2015-2017 also `overflow-wrap`. The with-downstream variants drop the same as their Baseline group.
- Changesets: cssints minor, @cssints/reset minor. cssints dist rebuilt.
